# Digital-Clock-using-Turtle-Tkinter-Function
This project is a simple and visually appealing Digital Clock built using Python. It uses the Turtle graphics module to display time and Tkinter for pop-up messages.
**Digital Clock using Python (Turtle & Tkinter)**
**Project Overview**
  This project is a Digital Clock built using Python that displays the current system time in real-time using the Turtle graphics module. It also uses Tkinter to show a welcome pop-up message.
**Features**
Real-time clock (HH:MM format)
Updates every second automatically
Clean UI (Black background + White text)
Welcome popup using Tkinter
Beginner-friendly and easy to understand
Technologies Used
Python 
Turtle Graphics 
Tkinter 
Time Module 
**Project Output**
Clock Display
Welcome Message
